Manhunt Radar

Un point GPS ponctuel, pas un suivi en direct.

Créer une partie ou rejoindre

Règle prévue : toutes les 5 minutes, chaque fugitif envoie un seul point GPS correspondant à sa position à cet instant. Les chasseurs le voient pendant 1 minute, puis il disparaît. Aucun trajet n'est enregistré.

Pour rejoindre, choisis ton équipe et saisis le code transmis par l'organisateur. Le code est privé : ne le publiez pas.

Avant de jouer

Chaque joueur doit accepter le partage de sa position. Jouez uniquement dans une zone autorisée, loin des routes dangereuses et sans obliger personne à partager sa position. Les chasseurs à vélo doivent respecter le code de la route. Le partage GPS nécessite une connexion et l'autorisation de localisation.
